# Вортекс — roadmap универсального preview

## Название

`Вортекс` — рабочее название модуля универсального предпросмотра файлов внутри Launcher v3.

Смысл: разные типы файлов проходят через единый preview-поток, но полноценное открытие и редактирование остаётся за нативными программами.

## Принцип

Launcher не должен становиться вторым Word, Excel или AutoCAD.

Launcher должен:

- быстро показать структуру объекта;
- дать поиск по длинным именам;
- показать preview;
- помочь понять, какой файл нужен;
- открыть исходный файл в нативной программе.

## Очерёдность

1. Word: `.doc`, `.docx`.
2. Excel: `.xls`, `.xlsx`.
3. Изображения: `.jpg`, `.jpeg`, `.png`, `.tiff`, `.gif` — факультативно позже.
4. Диагностика DWG/PDF пар — отдельное улучшение, если понадобится.

## Word stage

Принятая схема:

```text
DOC/DOCX → Microsoft Word → PDF cache → existing PDF render pipeline
```

Почему так:

- Microsoft Word установлен на текущем компьютере;
- LibreOffice не найден;
- уже есть принятый PDF viewer;
- не нужно писать новый viewer для Word;
- можно использовать существующие миниатюры, zoom, pan, fit, rotate, режимы просмотра и DPI-кэш.

Поведение:

- пользователь выбирает `DOC` или `DOCX`;
- нажимает `Отобразить`;
- backend конвертирует Word в PDF-кэш;
- PDF-кэш рендерится как обычный PDF preview;
- в viewer доступна кнопка `Открыть Word`;
- повторный просмотр использует кэш, если исходный Word-файл не изменился.

### Google Docs shortcut

Формат `.gdoc` — это не локальный Word-документ, а ярлык Google Docs.

Поведение для `.gdoc`:

- файл должен быть виден в дереве и в фильтре `GDOC`;
- файл можно выбрать и нажать `Отобразить`;
- встроенный preview не создаётся через Microsoft Word;
- viewer показывает карточку без локального preview;
- кнопка `Открыть Google Docs` открывает ярлык через Windows/Google Drive.

## Excel stage

Будущий вопрос сложнее Word:

- Excel состоит из листов/вкладок;
- области печати могут быть заданы или не заданы;
- один лист может быть очень большим;
- нужно решить, показывать листы как страницы, как вкладки или как PDF-export.

Предварительная схема:

```text
XLS/XLSX → Excel export → PDF cache → existing PDF render pipeline
```

Перед реализацией нужно отдельно протестировать качество и скорость.
