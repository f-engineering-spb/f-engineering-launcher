# Перенос Launcher на другой компьютер

Документ описывает, как запустить F-Engineering Launcher v3 на стороннем ПК
из портативного архива, собранного `scripts/package_release.ps1`.

## Что входит в архив и что нет

В архив `dist/FEngineering_Launcher_v3-portable-*.zip` входят:

- `app/` — бэкенд и фронтенд (весь код);
- `scripts/` — стартовые, упаковочные и конвертирующие скрипты;
- `docs/`, `tests/`, `tools/` — документация и вспомогательные утилиты;
- `requirements.txt`, `README.md`, `AGENTS.md`, `.gitignore`, `.editorconfig`;
- `runtime/manifests/` — манифесты объектов **для справки**: пути к объектам
  в них привязаны к старому ПК и на новой машине работать не будут;
- `runtime/tools/poppler/` — встроенный Poppler (pdfinfo/pdftoppm), сервер
  ищет его первым в этой папке, затем в кэше codex, затем в PATH.

В архив **не** входят кэши рендера (`runtime/cache/`, ~1.9 ГБ), логи и
`runtime/dwg-probe/`. Они пересоздаются автоматически при первом рендере.

## Требования на целевом ПК

1. **Windows 10/11** — проект Windows-only (PowerShell, COM, `.exe`).
2. **Python 3.14** — сервер запускается через `C:\Python314\python.exe`;
   если Python установлен иначе, поправьте `scripts/start_windows.ps1`
   (строка с выбором `$python`).
3. **openpyxl** — `pip install -r requirements.txt`.
4. **Microsoft Excel и Word** — нужны для конвертаций в preview
   (Excel→PDF, Word→PDF, XLS→XLSX) и для кнопок «Открыть …».
5. **Google Drive Desktop** с объектами проекта — папки объектов на новом
   ПК будут иметь другие пути, поэтому объекты нужно переимпортировать.

## Установка

```powershell
# 1. Распаковать архив, например:
#    C:\FEngineering_Launcher_v3

# 2. Установить зависимости Python:
cd C:\FEngineering_Launcher_v3
pip install -r requirements.txt

# 3. Запустить лаунчер (ставит UTF-8 и поднимает сервер на 8780):
.\scripts\start_windows.cmd
```

Открыть в браузере: `http://127.0.0.1:8780/`

## Переимпорт объектов (пути изменились)

Манифесты в архиве содержат пути старого ПК (`H:\Общие диски\000_Объекты
СПб\...`). На новой машине:

1. Подключите/смонтируйте объекты в нужную папку;
2. В лаунчере используйте «Импорт объекта» (или «Обновить объект»),
   выбрав корневые папки заново;
3. Старые манифесты можно удалить из `runtime/manifests/`.

Лаунчер не требует точного совпадения букв дисков: манифесты — просто
закэшированные списки файлов, которые пересоздаются при импорте.

## Проверка после переноса

1. Откройте объект с PDF и дождитесь рендера страницы (проверка Poppler);
2. Откройте `.xlsx` — проверка openpyxl/HTML-просмотра;
3. Откройте `.xls` — проверка автоконвертации через Excel;
4. Откройте `.doc` — проверка конвертации через Word.

Если PDF-превью не появляется, проверьте, что:
- Poppler лежит в `runtime/tools/poppler/Library/bin/` архива, либо
- `pdfinfo`/`pdftoppm` доступны из PATH.
