# Roadmap

## Phase 0 — Repository and workspace discipline

- Create clean repository.
- Define local runtime rules.
- Stop using old launcher folders as working roots.

## Phase 1 — Minimal Launcher shell

- Local server.
- Object list.
- Load/update/exclude object actions.
- Tree and format filters.

## Phase 2 — Accepted PDF viewer

- PDF render at selected DPI.
- Page thumbnails derived from high-quality renders.
- Accepted pan/zoom/fit/hand controls.

## Phase 3 — Other formats

- Excel.
- Word.
- Images.
- DWG strategy.

## Phase 4 — Modules

- Module registry.
- Input selection.
- Progress telemetry.
- Result viewer integration.
